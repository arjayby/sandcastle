# Sandcastle Brand Creation

Sandcastle is the workspace where founders create and refine a coherent brand system with an AI Brand Agent.

## Language

**Brand Builder**:
The founder or startup team member who directs the creation and refinement of a brand system.
_Avoid_: User, designer

**Brand Agent**:
The AI collaborator that generates a brand system from a brand brief and applies requested revisions.
_Avoid_: Chatbot, assistant

**Brand Brief**:
A company name and plain language description of what the company does. The description can also include audience, personality, positioning, preferred colors, visual direction, and things to avoid; the Brand Agent infers details that are not supplied.
_Avoid_: Prompt, questionnaire

**Brand Project**:
The container for one Brand Brief, one active Brand System, its Brand Canvas, and its revision history. A Brand Builder can own multiple Brand Projects.
_Avoid_: File, workspace, account

**Review Link**:
A private, revocable link that gives a viewer read only access to a Brand Canvas without project editing or collaboration controls.
_Avoid_: Invitation, public page, guest account

**Brand System**:
The coherent collection of logo, color, typography, voice and tone, photography, motion, interface foundation, and design tokens created for one brand.
_Avoid_: Brand kit, style guide

**Brand Artifact**:
A concrete, reusable output within a Brand Region, such as logo SVG, color values, type styles, voice examples, photography direction, motion parameters, interface examples, or design token code.
_Avoid_: Asset, content

**Brand Photograph**:
An original photograph created by the Brand Agent to match the Brand System and its photography direction.
_Avoid_: Stock photo, reference image

**Brand Canvas**:
The spatial workspace where a Brand Builder pans, zooms, selects, and focuses Brand Regions. The Brand Agent arranges the system while the Brand Builder directs it semantically.
_Avoid_: Dashboard, moodboard

**Progressive Generation**:
The process in which the Brand Canvas opens immediately and each Brand Region changes from an unfinished state to its finished state as the Brand Agent completes it. Finished regions can be inspected, but Semantic Revision becomes available only after all regions are finished.
_Avoid_: Loading screen, generation step

**Brand Region**:
A selectable area of the Brand Canvas devoted to one part of the Brand System.
_Avoid_: Section, page, frame

**Semantic Revision**:
A Brand Builder request expressed in brand or design language that targets either a selected Brand Region or the complete Brand System. It changes the target and any directly dependent regions needed to preserve coherence, and the coordinated changes form one undoable Revision.
_Avoid_: Edit prompt, command

**Revision**:
One accepted change to a Brand System. A Revision can contain coordinated changes to multiple Brand Regions and belongs to an undo and redo history of up to 20 entries.
_Avoid_: Version, save, edit
