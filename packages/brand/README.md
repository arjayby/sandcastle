# Sandcastle brand

`@sandcastle/brand` is the framework neutral identity foundation for Sandcastle applications.

Import `@sandcastle/brand/styles.css` once in an application entry point. Import token values from `@sandcastle/brand` when JavaScript or TypeScript needs the same source of truth. Logo files and local WOFF2 fonts are available through the public `assets` and `fonts` subpaths.

All Sandcastle product shell custom properties use the `--sc-` prefix. Generated Brand System custom properties keep the separate `--brand-` prefix.

The font files come from Fontsource 5.3.0. Their license texts are stored next to the font files.
